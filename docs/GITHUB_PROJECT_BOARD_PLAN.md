# Suggested GitHub Project board for group evidence

The assignment explicitly says to use **GitHub Projects**, not just commit code. Create a project board for the repository and track each task with an assignee, status, evidence (commit/PR link), due date and reviewer.

| Issue/title | Suggested status | Acceptance evidence |
|---|---|---|
| Preserve original xAPI CSV | Completed after verification | Compare SHA-256 in `docs/DATASET_AND_METHOD.md` |
| Validate schema and clean features | Completed after review | Run core tests and check source counts |
| Train and compare 3 classifiers | Completed after review | `models/metrics.json`; held-out confusion matrix |
| Build school analytics/dashboard | Completed after review | Screenshot and teacher demo |
| Build NLP study tutor | Completed after review | `/tutor` and test questions |
| Explain synthetic time-series exercise | Completed after review | `/forecast`, W1-W8 vs W9-W11 labels, source totals |
| Review safeguarding, privacy, and model limitations | Review | Document proposed use and limitations |
| Finalise 5+ rubric documentation sections | To do | Editable report and exported PDF verified |
| Add Grammarly check evidence | To do | Actual team-produced grammar report / proof |
| Sign originality declaration | To do | Every member signs actual declaration |
| Create and review poster | To do | Soft copy poster approved by all |
| Rehearse 20-minute presentation | To do | Demo script and timed run-through |
| Confirm Blackboard submission package | To do | Correct PDF, poster, slides, backups before 2 Nov at 23:59 |

**Do not claim that tasks have been done by specific teammates unless your GitHub commit/issues history proves that contribution.**
